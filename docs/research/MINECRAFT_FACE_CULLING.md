# Native block face culling

The textured mesh worker now follows the pinned client `Block.shouldRenderFace` order: a full neighbor face occludes immediately; the block's special `skipRendering` rule can remove a shared face; empty faces remain visible; otherwise the renderer tests whether any part of the current native face remains uncovered by the neighbor's opposite face. This uses the already-captured native face rectangles, independent of a resource pack's texture opacity or model-cube heuristic. Diagnostic cell views retain their ordinary integer cell culling.

`client-culling-inputs.mjs` performs method-owner reflection once per 1,286 block types, with zero state-pair evaluations. The seven owners are the original base behavior, half-transparent blocks, iron bars/panes, leaves, liquids, mangrove roots and powder snow. Captured type identities and the pinned client's bars tag support the original same-type, connection-property, fluid-family and vertical-root decisions. The preview uses the native default cutout-leaves setting. The core function also accepts an explicit fast-leaves setting for reference checks; no new application graphics setting is claimed.

`face-shapes.mjs` provides rectangular union coverage with native shape tolerance. It preserves holes and allows coverage split across multiple rectangles. Fluid occlusion shares the same bounded-input implementation. Shape-pair answers have a 256-entry least-recently-used cache, matching the original client's limit; keys use weak shape identities. There is no all-state or all-pair work in the mesh worker. Clipped neighbors are absent only for face visibility, so newly exposed cut faces remain selectable.

[Focused evidence](../evidence/client-face-culling-2026-10-22.json) records fourteen decisions from the original client, including equal/different glass, equal/opposing slab halves, a full block beside a slab, an empty current shape, roots, pane connections and cutout/fast leaves. Two actual worker cells remove their shared partial-block faces, then expose the clipped boundary while retaining voxel owners. Two authored union probes check split coverage and a real gap. The existing five-neighborhood fluid fixture is reused after sharing the rectangle operation; it remains a small changed-path check.

This does not qualify every state, tag combination, face-shape arrangement or custom model. Native metadata and inspected rules are pinned to the official 26.3 client identity; original class/source/asset bytes stay local. Actual browser/GPU/UI, complete geometry/light/material/biome-sampling behavior and native/release parity remain open. The native Wasm is unchanged, with corresponding sources refreshed and the development distribution updated.
