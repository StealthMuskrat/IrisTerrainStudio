# Pinned resource-pack resolution and animation

The rendering loader interprets resource metadata against Minecraft 26.3 resource format 97.1. `tools/assets/minecraft-client.lock.json` pins the official client by size, SHA-1 and SHA-256. Development inspection uses only selected original client classes and its animation shader; client code/assets are not committed or redistributed.

## Packs and resource ownership

`target-format.mjs` implements the inspected PackFormat and OverlayMetadataSection range rules, including major/minor endpoints, inclusive ranges, mixed older declarations and required/deprecated fields. A major-only upper endpoint includes all minor versions. It selects applicable overlay directories in declaration order; lookup searches the last applicable overlay first, then earlier overlays, then the root. Root metadata stays at the root. Old/inapplicable overlay assets are not flattened into the output. Existing explicitly selected packs whose declared format excludes the target are identified in the resource-pack dialog; this is not a format converter.

Filters apply after a pack's own resources have been searched, and stop fallback to lower-priority packs. The original manager selects matching namespaces and paths independently across the block list; it does not pair the two predicates per entry. Java Pattern.asPredicate searches within the identifier rather than requiring a whole-string match. The worker-free filter adapter implements a bounded ASCII regular subset: literals/escaped punctuation, dot, native ASCII character classes/ranges, anchors, capturing/noncapturing groups, nested alternation and `*`, `+`, `?`, `{n}`, `{n,}` and `{n,m}` repetitions. Thompson states avoid exponential backtracking, including nullable group cycles. Reluctance preserves boolean find existence; possessive matching, backreferences, lookarounds, flags and class intersections refuse explicitly. Absolute Java anchors are admitted because resource identifiers contain no line terminators. Limits are 128 rules, 1,024 pattern/path characters, 256 atoms, 64 alternatives, sixteen group levels, 1,024 repeat counts and 2,048 compiled states per pattern. Character-class membership is prepared once for the resource-character alphabet. Additional valid Java syntax remains an explicit adapter boundary. [Current scope and evidence](NATIVE_PNG_AND_FILTERS.md).

Texture metadata is searched from the highest-priority pack down to the pack that supplied the texture, with filter stops. Metadata from a lower pack cannot animate a higher pack's replacement texture. Dependency inspection uses the same resolved physical source paths and metadata cutoff. Export retains overlay provenance while flattening selected logical assets, alongside original source metadata/notices. Reopened bundles retain those exact selected bytes; all candidate model references are followed without state enumeration or weighted selection. Format resolution does not qualify model or GPU rendering parity.

## Pixels and animation

PNG bands now become owned RGBA8 pixels directly, retaining color under transparent alpha without a canvas/bitmap premultiplication or color conversion. Palette, grayscale, transparency keys, Adam7 and 8/16-bit bands use the existing bounded decoder. Rendering compares packed-gray transparency against the original PNG sample; the Iris/JDK image-map default retains its separately verified scale-before-key behavior. Sixteen-bit rendering uses the high byte. Profile/HDR/animation PNG chunks remain explicit boundaries for Minecraft texture loading. Native Iris image-map loading has a separately verified JDK default-image policy; it does not apply color conversion or animate APNG frames.

Animation frame dimensions follow the original metadata sizing: absent dimensions use square frames of the smaller source dimension; a single width/height override leaves the other dimension at its full source size. Empty or single-entry sequences use original frame-zero static behavior. Animation advances at whole 50 ms ticks, including repeated frames and per-frame durations. Interpolation uses original float progress quantized to thousandths and blends all RGBA channels, following the pinned animate_sprite_interpolate shader. The atlas uploads raw RGBA8 with duplicated gutters and keeps current alpha for picking; it starts an owned elapsed clock at its first update and skips unchanged ticks/pixels. Conservative blend classification avoids remeshing as alpha changes. This is an implementation of the inspected pixel/state rules, not an executed native GPU comparison; shader precision, material layers, mipmapping and real device behavior remain unqualified.
