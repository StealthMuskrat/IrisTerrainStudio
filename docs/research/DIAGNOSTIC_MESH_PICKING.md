# Diagnostic mesh reduction and emitted-face picking

Block-ID and physical-biome cell views now greedily combine compatible exposed unit-cell faces inside each world-aligned 16-block section. The worker uses a 256-entry typed plane mask, matching identity-color indices, constant white-carrier UVs, opaque materials and the existing diagnostic cube winding. It retains holes, color boundaries, clip cut faces and section boundaries. Textured Minecraft models, fluid surfaces, offsets, tint variation and animated sprites retain their existing individual quads. This scope avoids merging faces whose texture/material behavior would change.

Merged quads retain a base voxel owner plus a flag in the otherwise unused high owner bit. Admitted voxel owner indices are below 2^24. On a hit, the picker resolves the actual tangential cell from the hit point and the original rectangle bounds, then obtains its real block state and physical biome. Selection outlines the individual unit face. It does not return an arbitrary representative block for the whole rectangle. At an exact shared cell edge, floor/clamp selects the positive-side cell within the rectangle. GPU corner positions, material buffers and the compact picking transport retain their existing layouts; the flag requires the explicit diagnostic mesh scope.

Mesh face budgets apply after combination. Source/saved-face totals remain part of each cached section, so returning to a previous clip retains truthful totals without rescanning voxels. Retained preview details show emitted quads, section reuse and the number of diagnostic faces combined. Clip and appearance changes continue to retain generated arrays and camera ownership. Diagnostic colors bypass the textured fog/lighting branch, and their UVs are constant, so combining coplanar faces preserves these attributes.

The picker also builds a bounded spatial index from emitted corners for groups containing at least 64 quads. Each section groups quad centroids into at most 4 × 4 × 4 buckets. Every quad appears once; bucket bounds include every actual corner, preserving arbitrary geometry and overhangs outside the stored voxel bounds. Rays reject unrelated sections first, then visit intersected buckets in entry order before running the existing exact triangle, current-atlas alpha and material tests. Smaller groups retain the linear path. The index is owned by the committed immutable picker and is replaced with the mesh. Admission computes its allocation charge before allocation, with a 10 MiB limit per group; the existing combined 250,000-face admission and nonempty section ranges bound combined index storage to at most 13,000,000 bytes. Compact picking records retain their separate 24 MiB limit. Interaction work limits remain in place for pathological overlapping geometry. Timing, browser heap and actual GPU behavior have not been measured.

Focused checks use stored authored data only. A 24-cell solid box changes from 52 exposed faces to six quads: geometry/material/picking transport falls from 20,384 to 2,352 bytes. Surface decomposition matches the prior unmerged worker path. Eight selected rays return the same individual owner, block/biome and unit selection face. Two further tiny cases exercise an air hole, both identity-color views, negative/unaligned origins and section boundaries. Clip/empty/reuse, retained arrays, scope refusal and the actual preview-details helper pass.

The spatial check uses 128 stored cells / 304 emitted faces and 80 stored cells / 480 cutout faces. Four selected rays compare with the same picker's linear traversal: each tests 8–14 quads rather than 304 and returns the same result. Misses, alpha pass-through, overhang hits outside the stored bounds and nonfinite indexed-geometry refusal pass. These are operation counts from small fixtures, not a measured performance qualification. Existing four-cell view ownership and 50-cell section-cache checks also pass. Their controlled renderer services do not rasterize; the section-cache fixture now uses current raw RGBA/model-group services and an admitted atlas size, and writes current results locally without replacing historical evidence.
