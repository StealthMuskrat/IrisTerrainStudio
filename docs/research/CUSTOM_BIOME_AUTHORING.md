# Native custom biome authoring previews

The browser terrain context now admits content-addressed custom biome definitions through the original `GenerationRegistryContractFactory.customBiomeResourceKey` and `IrisBiomeCustom.generateJson` with the pinned Minecraft 26.3 data fixer. The native physical biome actuator uses these keys through ephemeral, context-owned handles. Definitions are registered before native kernel construction, including admitted upper/stack dimension references. This replaces the former blanket refusal for this authoring path.

This is `content-addressed-authoring`, with `nativeRegistryEpoch: false`. It does not install a Minecraft registry, qualify a saved-world registry contract, or establish a production registry epoch. The immutable epoch resolver still refuses. Original readable-name registration is stored locally and bounded; live global alias lookup is unavailable. Original key hashing, canonical semantic JSON and UTF-8 behavior execute through the existing verified SHA/UTF adapters. Integer color decoding replaces the AWT object boundary. Gson streaming tree IO avoids unrelated reflective/SQL adapter initialization; original native semantic canonicalization remains in the factory. Corresponding upstream and adapter source accompanies the module.

Each terrain context permits at most 128 definitions, 65,536 JSON characters per definition and 1,048,576 JSON characters in total. IDs are limited to 256 characters, finite climate values are required and spawn metadata is limited to 64 entries per definition. Semantic JSON parsing permits 4,096 nodes and depth 64, and refuses duplicate members or trailing input. Transport independently checks scope, unique native keys, climate/color types and bounded labels. All definitions and local names are discarded on release or failed construction. These admission budgets do not change native algorithms or insert configuration defaults.

Generated volume metadata retains the complete native JSON strings and readable source labels. The client charges retained strings against its existing generation cache budget. Model, fluid and optional biome-blend color lookup uses the retained definitions before vanilla biome metadata. Climate values use the native float boundary; missing/invalid definition metadata refuses instead of inventing colors. Terrain replacement cannot change an older retained volume's colors. Voxel inspection shows the source identity and downloads the exact retained native definition as `custom-biome.json`; a replaced preview refuses the old action. Unknown authored source fields remain in the original pack; generated definitions are native outputs, not source rewrites.

The focused check uses two small custom derivatives in one authored 16 × 32 × 16 terrain fixture. One Unicode ID exercises the original identity path; one definition uses explicit grass/foliage colors and the other uses climate colormaps. Two identities and native definition objects match original Java. Four selected physical biome keys and two materials match the original actuator. The JVM physical fixture uses virtual custom key handles: it does not register a world. Eight colors match original Minecraft effects-codec/biome-color calls using authored colormaps. Actual Wasm/worker/client transport and actual mesh-worker model/fluid paths pass, with cache reuse, retained-array ownership, invalid-metadata refusal, constructor failure, cleanup and recovery. A controlled application helper checks exact download bytes and stale-action refusal; it is not a browser test. See [evidence](../evidence/native-custom-biomes-2026-10-23.json).

Complete option coverage, real custom registry epochs, global aliases, registry/history/world lifecycle, spawn/particle behavior, cross-context interactions, complete terrain/client parity, real browser/GPU and release qualification remain open. No world chunks are modified. No registry re-export, block-state enumeration, broad suite or GitHub workflow is needed for this batch. Final comprehensive program verification remains deferred until implementation is complete.
