# Pinned cuboid geometry and element rotation

The target is the official Minecraft 26.3 client, SHA-256 `4508d006323f24fa02876310c192d739af56516eb259000ac50f0909a68c9a2d`, with its declared JOML 1.10.9 dependency. Native client code/assets and decompiled references remain local. Only adapter code, authored fixtures, hashes and numerical evidence are committed.

The previous renderer used a legacy five-angle element transform and double-precision trigonometry. The native target accepts finite single-axis angles and Euler X/Y/Z values. A declared axis or angle selects the single-axis form; Euler fields are otherwise independently optional once at least one is present. Axis names normalize to lowercase. The rotation origin is required and scaled from model units. Malformed/null fields refuse rather than receive invented defaults. This adapter admits finite binary32 numeric inputs and boolean rescale values; it does not claim the native parser's complete string/coercion behavior.

`cuboid-geometry.mjs` retains the native single-axis or Z/Y/X matrix construction, binary32 degrees/radians/sine/cosine arithmetic and per-column rescale. The reference uses JOML's default non-fastmath/non-FMA profile, explicitly recorded and checked. Rescale uses the reciprocal of the largest absolute transformed-axis component, rather than the legacy one-axis cosine approximation. Geometry is transformed around the element origin before the captured block-model rotation. Native from/to bounds are enforced after binary32 decoding. Nonfinite geometry refuses before mesh publication.

Model identity transforms now preserve small coordinates without unnecessary center subtraction/addition. Identity UV-lock transforms likewise preserve small UV coordinates. Nonidentity vertex and UV transforms retain their captured model-state matrices. Atlas interpolation uses float32 arithmetic. Face normals/direction selection follow the original geometry calculation and strict native direction tie order. Degenerate normals retain the native UP fallback; zero-area faces are not replaced with invented geometry.

When the element has no rotation object, native FaceBakery reorders corners and their UVs to the final direction's canonical winding. This matters for model quarter-turns, inverted bounds, triangle diagonals and picking. Element-rotated faces keep their original order, including explicitly present identity rotations. The original selected direction is retained on each baked quad and takes precedence over recomputing a direction from an approximate normal during flat shading. Explicit shade overrides still take precedence. All static and contextual model baking paths now share an 8,192-face admission limit; model-state matrices are resolved once per application. Worker vertex/material/picker layouts and stored voxel ownership stay unchanged.

## Focused reference

`python3 tools/checks/capture-client-cuboids.py` restores only checksummed development inputs if absent. It verifies the locked client and version-metadata identities, downloads a bounded selected set of that exact metadata's dependency artifacts with their declared size/SHA-1 and records SHA-256 values. It uses the pinned Java toolchain and runs the original CuboidModelElement/CuboidFace parsers, CuboidRotation, FaceBakery, FaceInfo and model-state transforms. A small owned sprite carrier supplies fixed atlas coordinates; interning returns the same native objects. No native geometry/rotation method body is rewritten. No world, renderer, GPU, native block-state registry exporter or Iris build is needed for this reference.

`node tools/checks/client-cuboids-smoke.mjs` compares 41 faces across fifteen tiny parser/baker fixtures: nine accepted cuboids and six refused inputs. All selected vertex/UV binary32 bit patterns, element matrices, shade directions and winding match. Cases include nonstandard single-axis angles, uppercase axes, axis-over-Euler precedence, noncentral origins, Euler rescale, explicit zero rotation, identity UV locking at a small coordinate, model quarter-turns, inverted extents and degenerate faces. Missing origins/rotation values, null Euler/UV fields, empty faces and out-of-bounds coordinates refuse in both paths.

An actual resource stack preserves inherited elements/material slots and source bytes before baking. Two actual Node mesh-worker cells (eight emitted faces) preserve original shades, cached vertex buffers, source voxels and picker ownership. These checks are selected implementation evidence, not full native geometry or rasterization qualification. Cross-runtime trigonometry over all binary32 inputs, nondefault JOML profiles, complete parser coercions, actual WebGPU/browser pixels, native lightmaps/AO/environment shaders, authentic client quart/Voronoi biome sampling, F8thful assets and complete native terrain/reference/release qualification remain open. No broad suite or state/pair sweep runs during this batch.
