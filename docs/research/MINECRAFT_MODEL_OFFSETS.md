# Native model displacement and picking ownership

The client input capture now inspects each type's default-state offset-function metadata. It identifies the original XZ/XYZ functions by their class identity against the original Properties.offsetType factories, captures the block's original horizontal/vertical float limits, and refuses an unknown function. This reads metadata once per 1,286 block types; it does not enumerate state combinations or evaluate offset cells. The pinned client contains 39 profiles: 34 XZ and five XYZ.

`model-offset.mjs` retains the original position seed at (x,0,z), bit fields, binary32 fraction divisions, double displacement arithmetic and native clamp limits. Offset-bearing types use a conservative non-occluding classification. The mesh worker applies the float displacement to both render vertices and picking records; section bounds include those translated positions. Picking still identifies the original stored voxel owner. Block/biome diagnostic cells retain their exact integer extents. Voxel inspection reports the selected cell's model displacement independently of its stored block coordinate.

[Offset evidence](../evidence/client-model-offsets-2026-10-22.json) records six original client offsets, including a negative coordinate, vertical movement, a horizontal clamp and equal XZ with different Y. Two actual displaced mesh-worker cells retain the correct owner through triangle picking. The small existing eight-transform/eleven-selection/three-condition fixture remains in this focused check, with no state/volume sweep or terrain generation. The reference math library matches the JOML identity in the official pinned client version metadata.
